# Merhaba, Ben Merve Altınsoy 👋

Mühendislik eğitimim boyunca gömülü sistemler, bilgisayarlı görü, havacılık telemetri altyapıları ve uç birimlerde yapay zekâ uygulamaları üzerine odaklandım. 

Teknik projelerimde donanım seçiminden (mikrodenetleyiciler, sensörler, haberleşme modülleri) saha testlerine ve model entegrasyonlarına kadar sürecin bizzat mutfağında yer almayı seviyorum. TEKNOFEST takımlarında takım kaptanlığı, danışmanlık ve elektronik alt sistem üyeliği gibi sorumluluklar üstlendim.

---

### 🛠️ Teknik Yetkinlikler

* **Gömülü Sistemler & Donanım:** Raspberry Pi 3/4, Arduino Uno, Deneyap Kart (ESP32-S3), Pixhawk, Çift Motor Sürücüler (L298N), DC/Servo Motorlar.
* **Sensörler & Modüller:** QTR Çizgi Sensörleri, Ultrasonik (HC-SR04), IMU (MPU9250), Barometre (BME280), GPS (U-blox NEO-8M), RRC3 Altimetre.
* **Haberleşme Protokolleri:** LoRa RF, RF Telemetri, Bluetooth (HC-06), UART, I2C, SPI.
* **Bilgisayarlı Görü & Yapay Zekâ:** OpenCV (Python), TensorFlow Lite (Edge AI), Google Gemini API (Multimodal / LLM entegrasyonu).
* **Diller & Araçlar:** Python, C/C++ (Arduino IDE), FastAPI, Git & GitHub.
